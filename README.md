# 《播种者传说》(Sower Legend)

一款单文件 + three.js 的 3D 宇宙探索游戏。驾驶飞船探索星系，接触 14 种文明，
收集真言、建立信标、穿越星门，在黑洞/伽马暴/暗宙风暴/遗忘之风/修复者等宇宙天灾中求生，
最终抵达方舟核心、揭开「大寂静」的真相。

## 文件
- `index.html` —— 游戏全部逻辑与界面（单文件）
- `three.min.js` —— three.js 引擎（r128 时代，2021 版）

## 本地运行
直接双击 `index.html` 即可（需保持 `three.min.js` 与它在同一目录）。

## 部署到 GitHub Pages
1. 在 GitHub 新建一个仓库（如 `sower-legend`）。
2. 上传本目录的 `index.html` 与 `three.min.js` 两个文件。
   （可用 `git init && git add . && git commit -m "init" && git remote add origin <你的仓库地址> && git push -u origin main`）
3. 打开仓库 **Settings → Pages**，在 **Source** 选 `main` 分支、根目录，点 Save。
4. 几分钟后访问 `https://<你的用户名>.github.io/sower-legend/` 即可在线游玩。

> 注意：若想**单文件部署**（只传 `index.html`），需把 three.js 换用 CDN 或内联，
> 可后续改造。当前保持本地 `three.min.js` 版本一致，最稳妥。

## 联机化路线（需后端服务器）
当前为纯前端单机（存档在浏览器 `localStorage`）。真正联机需引入后端，可选：
- **A. WebSocket 实时多人**（Node.js + `ws`）：服务器同步各玩家位置/文明状态，客户端把
  本地 `localStorage` 存档改为服务器存档。改动较大（账号/房间/状态同步/防作弊）。
- **B. 轻量在线要素**：不建实时服务器，改用「宇宙种子分享」——生成一个随机种子链接，
  朋友打开同一种子看到相同的星系布局，适合先快速上线。
- **C. 混合**：先做 B（零后端、立即可上线），再迭代到 A。

## 操作键位
- `W A S D` / 方向键：转向
- `Shift`：曲速引擎
- `E`：发射/降落/起飞/收集/激活信标/穿越星门
- `F`：与文明对话/继续对话
- `B`：在行星表面建立信标
- `ESC`：结束对话
- `L`：复制「宇宙种子」分享链接（B 路线 · 种子分享）
- 空格/回车：开始/接受使命

## 种子分享（B 路线，已实现）
- 每个宇宙由「种子」决定：星系类型/位置、星球类型/位置、文明类型/发展阶段/名称均从种子确定性生成。
- 打开 `index.html?seed=<种子码>`（如 `?seed=abc123`）即可复现同一个宇宙。
- 游戏中按 **L** 复制当前宇宙的分享链接，发给朋友后打开同一种子即可看到相同的星系布局。
- 注：粒子特效等纯视觉效果仍为随机（不影响宇宙结构）。
